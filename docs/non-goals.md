# Non-goals

The MVP does not attempt to provide:

- general model-decision causal explanations;
- token-level attribution;
- full agent or world replay;
- exact replay of live external-tool side effects;
- arbitrary schedule exploration or concurrency model checking;
- complete gateway, subagent, or cron tracing;
- general secret detection;
- automatic source patch application or automated program repair;
- proof that a structural repair improves model behavior;
- broad coverage claims over Hermes production bugs.

These are boundary conditions for valid conclusions, not deferred promises. A feature may be added later only with a new evidence contract and evaluation plan.
