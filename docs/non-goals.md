# Current Release Non-Goals

The current release does not implement:

- Session Isolation detector family.
- Failure Attribution Control Plane.
- Agent-as-a-Judge.
- GEPA or DSPy skill evolution.
- Automatic `SKILL.md` edits.
- Skill shadow/canary deployment.
- Memory Graph.
- Graphiti, HippoRAG, or Neo4j integration.
- Learned memory reranking.
- Full agent replay.
- Automatic source repair.
- Production canary.
- Automatic rollback.
- Cross-machine distributed tracing.

These are future systems or future release gates. They must not be smuggled
into Phase 0 or Phase 1.
