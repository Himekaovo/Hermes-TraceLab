# Phase 0 Identity Ownership

## Scope

This table records the identity owners that Phase 0 must verify in the real
Hermes runtime. It is not a substitute for runtime inspection.

| Identity | Expected lifecycle owner | Current status | Notes |
| --- | --- | --- | --- |
| `run_id` | Hermes run/session coordinator | UNKNOWN | Runtime not bound. |
| `invocation_id` | Tool invocation creator | UNKNOWN | Must not be generated by recorder. |
| `attempt_id` | Retry/executor attempt owner | UNKNOWN | Retry must create distinguishable attempts. |
| `raw_outcome_id` | Executor/tool outcome owner | UNKNOWN | Must survive normalization. |
| `normalized_result_id` | Result normalization component | UNKNOWN | Must reference raw outcome. |
| `binding_decision_id` | Binding/assembly component | UNKNOWN | Must exist as a real seam before detector work. |

## Recorder Rule

The recorder may create `event_id` values for trace events. It must not create
business lifecycle identities such as `invocation_id`, `attempt_id`, or
`raw_outcome_id` to compensate for missing runtime support.

## Current Finding

Because no Hermes runtime is bound, all lifecycle identity ownership remains
`UNKNOWN`.
